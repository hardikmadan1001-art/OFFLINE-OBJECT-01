# OFFLINE local edition

This local rebuild follows the Why Zero and Pear study. It uses authorized Why Zero art and timing, replaces company logos and education headlines with symbols and research about distraction, and ends in a forest with the OFFLINE OBJECT 01 player suspended from a branch. The finale uses a photographed pine forest and a scanned branch alongside original Blender and Three.js work.

## Run

```sh
npm ci
npm run dev
```

Open `http://127.0.0.1:4173/`. Draw a loop, then scroll and hold where the film asks. Visit `/palette.html` to compare or save a color treatment. Use `/object.html` for the complete product reveal, `/object.html#object` for the interactive player, and `/object.html#signature` for the footer artwork. `npm run build` produces `dist/`. `npm run preview` serves the last build on the loopback interface.
